# Project notes (for the next working session)

**The Trenches**: a browser multiplayer top-down shooter, Green vs Red, in the style of Foxhole's trench warfare.
Started 2026-10-18 from the `topdown` scaffold, which came from the Pawpad launchpad project.

## Decisions so far
- Two teams, picked or random, kept balanced (you cannot join the bigger side).
- Map: a trench line on each side, cover in no-man's land, a capture point in the middle. `shared/map.json` is generated by `scripts/make-map.mjs` and mirrored left/right so it is fair.
- The server decides everything (`server/sim.mjs`): movement, shots, damage, capture, rounds. Clients only send intent (move, aim, fire).
- Rifle: 34 damage, 100 hp (3 hits), one shot per 450 ms, bullets travel at 720 px/s and stop at cover. No friendly fire. 4 s respawn, 1.5 s spawn protection.
- Capture point: progress moves with the number of soldiers inside (contested = frozen, empty = drifts back). Full bar wins the round; 6 minute timer, then whoever is ahead. 10 s pause, then a new round.
- Guests can play with a callsign. Wallet sign-in exists (`server/auth.mjs`, free message signature) but is hidden until `VITE_WALLET_LOGIN=1`.
- No chat (moderation burden). No persistence yet.
- The coin scripts from Pawpad are parked in `scripts/` (dbc-config, launch-token, dbc-fees, sweep, new-wallet). Nothing in the game uses them.
